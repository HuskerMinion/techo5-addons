# Contributing

To get an add-on listed, or a new version of one, open the
[Submit an add-on](https://github.com/HuskerMinion/techo5-addons/issues/new?template=submit-addon.yml)
form. The [README](README.md#for-authors-getting-an-add-on-listed) says what an add-on needs and how
it is reviewed.

Changes to `catalog.json` come by pull request from the maintainer, after review: entries are written
from the release and its files are pinned with `mkcatalog -pin`, never by hand. Please don't open a
pull request that edits the catalog; use the form, and the entry is added for you.

Fixes to the README, the form or the check workflow are welcome as pull requests.
